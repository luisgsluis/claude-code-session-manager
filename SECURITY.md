# Security

CCSM manages Claude Code sessions and handles credentials, so treat it as a
security-sensitive project.

If you find a vulnerability, report it privately through **Security → Report
a vulnerability** on this repository
(<https://github.com/luisgsluis/claude-code-session-manager/security/advisories/new>)
— please don't open a public issue. Include what you found and, if possible,
steps to reproduce.
